# Administrative boundary data

The GeoJSON files in this directory were retrieved from the Alibaba Cloud DataV
GeoAtlas boundary API on 2026-09-03.

- Country: `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`
- Province-level detail: `https://geo.datav.aliyun.com/areas_v3/bound/{adcode}_full.json`

The application serves these files locally and does not call the DataV API at runtime.
